# TOS 연동 협의 자료 — 우리가 지금 낼 수 있는 것

작성 2026-08-11. 대상: TOS 벤더 / 고객사 IT 와의 기술 세션.
목적은 **협의를 우리 쪽 미지수 없이 시작하는 것**이다. 아래 §1~§3 은 이미 라이브로
생산되고 있는 값이고, §4 는 상대에게 받아야 답이 나오는 것이다.

> 이 문서가 필요한 이유: 디스커버리(2026-07-22)에서 "실배차 연동의 최대 장애물은
> 인터페이스가 아니라 **식별자**"라고 판정했다 — 당시 우리 출력에는 컨테이너번호가 없어
> "어느 작업지시인지 지목할 수 없었다". **그 제약은 2026-08-10 에 해소됐다.**

## 2. 우리가 답할 수 있는 것

- **대상 식별자**: 컨테이너번호(`contno`)로 상자 한 개를 지목할 수 있다. 채움률 **100%**
  (최근 30분 추천 1,198행 전수). 필요하면 `(vessel, queuename, contno)` 복합키도 낼 수 있다.
  ⚠ `queuename` 은 **선박·항차 간 재사용**되므로 단독 키로 쓰면 안 된다.
- **주기와 지연**: 60초 주기. 상류(TOS Oracle 미러) 신선도는 12~62초.
  작업목록이 300초 이상 낡으면 **추천 생산을 스스로 멈춘다**(2026-08-11 배선·드릴 검증 완료).
- **중복 방지**: 같은 상자를 연속 추천하지 않는 장치가 이미 돈다(TTL 180초). 추천→TOS 반영
  사이의 1~2분을 덮는 값이다. 라이브 게이지로 배선 건강도를 상시 확인한다.
- **정지 시 거동**: 우리가 멈추면 추천이 안 나갈 뿐이다. 지금은 그림자라 현장 영향 0.

## 3. 우리가 이미 정한 것 (협의 대상 아님·통보 사항)

- **늦는 추천도 그대로 낸다.** `feasible=false`(마감 못 맞춤)여도 보낸다. 늦었다고 빼면 그
  상자는 아무도 안 가져가 더 늦어지기 때문이다. 늦음은 감추지 않고 화면에 표시한다.
- **냉동·위험물·OOG 를 빼지 않는다.** TOS 가 이들을 정상 배차하고 전용 트럭대도 없음을
  실측으로 확인했다(최근 7일·분모 109,877상자: 위험물 2.13%·냉동 3.22%·OOG 0.18%,
  위험물 운반 트럭 480대 중 478대가 일반 화물도 나름).
  → **TOS 측에 사람이 지키는 특별 절차가 있다면 알려달라.** 그런 규칙은 우리 자료에
  남지 않아 확인할 수 없고, 있다면 결정을 뒤집어야 한다.
- **TOS 배차를 흉내내지 않는다.** 시작 시점에만 "이미 배차된 상자"를 제외하고, 그 뒤로는
  TOS 가 무엇을 배차했는지와 무관하게 우리가 판단한다.

## 4. TOS 측에 받아야 하는 것 (이것 없이는 견적·일정 불가)

| # | 질문 | 없으면 생기는 일 |
|---|---|---|
| 1 | 외부 배차 권고를 받는 **공식 인터페이스**가 있는가(테이블/API/메시지)? 스키마·인증·호출 제한은? | 출력 채널 설계 자체가 불가. 형태(파일/테이블/REST/큐)에 따라 공수가 수 배 |
| 2 | 지시 1건을 특정하는 **최소 키 집합**은? 컨테이너번호로 충분한가, 작업지시 ID(MSNSEQ)가 필요한가? | 우리는 컨테이너번호를 낼 수 있다. MSNSEQ 가 필수면 추출·스키마 추가 |
| 3 | **Ack·멱등성** 규약은? 커맨드 ID·재전송·순서 보장이 필요한가? | 단순 폴링과 신뢰성 큐는 공수가 배 이상 차이 |
| 4 | 우리가 멈추면 **TOS 기본 배차로 자동 복귀**됨을 보증할 수 있는가? 부분 적용 시 분리 단위(크레인/트럭/작업유형)는? | 폴백 보증 없이는 부분 적용 안전 승인이 안 난다 |
| 5 | 운영자가 권고를 **채택/기각한 사실을 기록**할 경로가 TOS 에 있는가, 아니면 우리가 화면을 만들어야 하는가? | 파일럿 단계 통과 근거를 만들 수 없다(지금은 "TOS 가 결과적으로 같은 상자를 골랐나"만 잴 수 있고, 그건 사람의 판단이 아니다) |
| 6 | 현장 이벤트 → TOS Oracle 반영까지의 **실제 지연**은? | 종단 지연 SLA 를 근거 없이 약속하게 된다 |
| 7 | 냉동·위험물·OOG 배차에 **사람이 지키는 절차**가 있는가? | §3 의 "빼지 않는다" 결정을 뒤집어야 할 수 있다 |
