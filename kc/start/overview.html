지식센터 개요

이 사이트는 WP-TT 프로젝트의 단일 출처(single source of truth)입니다.

온보딩 리빙 문서

컨테이너 터미널 TT(트랜스퍼 트럭)의 모니터링·배차·사이클 분석과 AI 배차 연구에서 알아낸 것을 한곳에 쌓아, "예전에 알아낸 걸 다시 까먹는" 손실을 막는 것이 목적입니다. 흩어진 메모·코드 주석·세션 인수인계 파일을 대체합니다.

섹션 안내

섹션무엇을 담나
시작 & 기획이 개요 · 글쓰기 규칙 · PRD · 로드맵 · 정식 전환 계획. 새 사람·새 글의 출발점.
대시보드 가이드각 화면의 모든 값이 어디서 오고, 어떻게 계산되고, 무엇을 뜻하는지 (리빙).
데이터 & 지표TOS 추출 · 실시간 피드 · KPI 산출 · 사이클 분해의 단일 출처.
배차 (2단계)어느 트럭을 어느 작업에 — 설계 · 여정 · 롤아웃 · 시뮬레이터 · 조사 기록 · ADR.
학습 · 예측 & 리서치이동시간 · 곧-유휴 등 예측 모델과 내구성 있는 도메인 발견.
레퍼런스용어집 & FAQ · 참고자료 · 클라우드 용량 산정.

어떻게 쓰나 (요약)

  • 글을 쓰기 전에 글쓰기 규칙을 확인하세요 — 페이지 골격 · 상태표시 · 링크 규칙이 모든 글에 일관 적용됩니다.
  • 리서치 · ADR · 실험처럼 사실 정확성이 중요한 글은 상단 배지로 상태·검토 맥락을 답니다.
  • 검증 안 된 수치 · 식별자 · API 동작은 단정하지 말고 (미검증)으로 표기하고 "열린 질문"에 남깁니다.
  • 관측하지 못한 값은 추정으로 채우지 않고 비워 둡니다(NULL).
이 사이트는 손수 만든 정적 HTML

Astro Starlight에서 이관한 자체 정적 HTML 사이트입니다. 좌측 나브는 kc/assets/kc.js의 NAV에 정의되고, 공용 셸(사이드바 · 브레드크럼 · 우측 TOC · 검색 · 이전/다음)을 스크립트가 자동 주입합니다. 운영 서버가 /kc/로 서빙하므로 내부 링크는 /kc/… 절대경로를 씁니다.
