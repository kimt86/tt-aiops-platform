실제 적용까지 — 안전하게 켜는 단계별 계획

2단계 최적 배차를 실제로 켜기 전에 무엇을 어떤 순서로 확인하고 어떤 안전장치를 두는지 — 단계·통과 기준·되돌리기·아직 모델에 없는 위험까지. 기술 용어 없이 읽을 수 있게 썼습니다.

배차 · 계획

지금 어디에 있나

지금도 여전히 A단계 — 그림자(연습) 모드입니다. 컴퓨터가 "이 트럭을 이 작업에 보내면 좋겠다"를 계속 계산·기록하지만 실제 배차는 전혀 건드리지 않습니다. 여기서 이미 확인된 것:

  • 최적 배정이 단순 방식보다 전체 도착시간을 줄이고 급한 작업 마감 누락도 줄였습니다.
  • 추천이 흔들리지 않습니다(안정적). 이동시간은 실제 GPS 주행 기록으로 배운 값(추론 도로망 경로시간→실제 곡선, 2026-07-02~)을 씁니다.
2026-08-06 — 추천을 고르는 기준이 바뀌었다

추천할 일을 고르는 기준이 배차 마감이 이른 순으로 담는 방식으로 바뀌었습니다(자세한 내용은 배차 마감 문서 5장). 여전히 A단계 그림자이므로 실제 배차는 바뀌지 않습니다 — 바뀐 것은 그림자 안에서 어떤 일을 추천으로 고르느냐뿐입니다. B단계의 첫 도구인 라이브 맵 권고 오버레이는 이미 나와 있고(아래), TOS·관제와 직접 연결하는 것은 아직 협의 전이라 손대지 않았습니다.

  • A. 그림자 (지금) — 추천을 기록·검증만. 운영 무간섭.
  • B. 참고 표시 — 추천을 현장/관제에 보여주되 따를지는 사람이 결정. 추천과 실제 결정을 나란히 비교.
  • C. 제한 적용 — 아주 좁은 범위(한 블록 묶음·한 교대·소수 트럭)에서만 실제로 따름. 언제든 끌 스위치와 함께.
  • D. 전체 적용 — 위 단계들이 충분히 안정적이라 확인된 뒤에만.
지금 가능 — 라이브 맵 권고 오버레이

라이브 맵에서 "AI 배차 권고"를 켜면 추천이 트럭→작업 지점 점선으로 표시(초록=제때, 주황=늦음, 라벨에 트럭→크레인·예상 분). 참고용일 뿐 실제 배차는 안 바뀝니다. B단계의 첫 도구.

넘어가기 전 통과 기준 (Go / No-Go)

각 단계로 넘어가려면 충분한 기간 아래가 모두 성립해야 합니다.

  • 효율이 실제로 더 낫다 — 트럭 도착·대기가 기존보다 나빠지지 않음.
  • 마감을 더 놓치지 않는다 — 급한 작업 마감 누락이 늘지 않음.
  • 크레인을 굶기지 않는다 — "트럭이 없어 멈추는" 일이 늘지 않음(오히려 줄어야).
  • 추천이 안정적이다 — 트럭이 작업을 들락날락하지 않음.
  • 현장 거부가 적다 — 사람이 추천을 뒤집는 비율이 낮음.

하나라도 어긋나면 넘어가지 않고 이전 단계로 돌아갑니다.

안전장치

가장 중요 — 끄기 스위치

언제든 한 번에 기존 방식으로 되돌릴 수 있어야 합니다. 이상이 보이면 즉시 끄고 원인을 본 뒤 다시 켭니다.

  • 좁은 범위부터 — 정해진 구역·시간·대수로 한정. 문제가 나도 영향이 작게.
  • 바닥 안전선 — 어떤 경우에도 크레인을 멈추게 두지 않음. 추천이 이상하면 가장 가까운 가용 트럭을 보내는 기본 동작으로 자동 전환.
  • 사람이 항상 우선 — 현장/관제가 언제든 추천을 무시·수정.
  • 그림자는 계속 — 실제 적용 중에도 "안 따랐다면 어땠을까"를 같이 기록.
  • 상시 감시 + 경보 — 마감 누락·크레인 멈춤·흔들림이 기준을 넘으면 자동 경보, 필요시 자동 끄기.

아직 모델이 모르는 것 (위험)

추천이 좋아도 컴퓨터가 아직 보지 못하는 현장 규칙이 있습니다. 실제 적용 전에 어느 것을 반영하고 어느 것을 알고도 넘어갈지 정해야 합니다.

  • 특별 취급 — 위험물·냉동·초과중량·우선 화물 등. 2026-08-18 확인: TOS도 이런 화물을 일반 화물과 똑같이 배차합니다 — 전용 트럭대도, 전용 배차 묶음도, 앞당김 표시도 없습니다. 그래서 배차 후보에서 빼지 않기로 했습니다. 다만 배차 밖에 절차가 있습니다 — 특히 배에 실을 냉동 컨테이너는 싣기 전에 전원을 뽑아야 하는데, 이 일이 TOS가 트럭을 붙인 뒤에 이뤄지는 경우가 사흘에 300건 있었습니다. 트럭이 실제로 기다리는지는 아직 재지 않았습니다. 배차 마감 5장 참조.
  • 장비·통행 제약 — 특정 트럭만 가는 곳, 일방통행·통제 구역, 정비 중 장비.
  • 운영자의 의도 — 사람이 아는 단기 계획(곧 들어올 배, 장비 이동 예정 등).
원칙

모르는 건 건드리지 않는다. 모델이 다루지 못하는 작업·구역은 적용 범위에서 빼고 기존 방식 그대로 둡니다.

되돌리기 계획

  • 이상 징후(마감 누락 급증·크레인 멈춤·흔들림)가 보이면 즉시 끄기 → 기존 방식 자동 복귀.
  • 끈 뒤 무엇이 어긋났는지 그림자 기록으로 분석.
  • 원인을 고치고 이전 단계부터 다시 시작.
한마디로

천천히 · 좁게 · 되돌릴 수 있게. 그림자에서 충분히 확인 → 사람이 보며 판단 → 아주 좁은 범위에서 실제로 따라봄 → 기준 통과 시에만 확대. 언제든 끌 수 있고 크레인은 절대 멈추지 않게.
