AMR 작업 할당 요구사항 및 우선순위 정의 (초안)

컨테이너 터미널 작업은 ① 작업 우선순위, ② 안벽크레인 연동 타이밍 측면에서 고유한 운영 특성을 가진다. 본 문서는 이 특성으로부터 자동화 운반차량(AMR)의 작업 할당 요구사항과 우선순위 기준을 도출하고, 이를 충족하는 2단계 배차 로직을 제안한다.

배차 · 요구사항

‘작업 할당’은 어느 작업을 어느 차량이 수행할지를, ‘작업 우선순위’는 후보 작업 가운데 어느 것을 먼저 처리해야 하는지를 의미한다. 본 문서는 개념 수준의 요구사항을 다루며, 구체적 수치는 상세 설계에서 제시한다.

1. 작업 할당이 반영해야 할 운영 특성

1.1 작업 우선순위 체계

  • 최상위 기준은 선박 출항 예정시각(ETD). 각 선박은 ETD 이전에 양하·적하 물량을 모두 완료해야 한다.
  • 최소 단위는 컨테이너 1개의 단위 작업(move)이며 상태(계획→대기→진행→완료)로 관리. '대기'=미배정 미충족 수요, '진행'=배정되어 처리 중.
  • 각 작업에 예정 작업시각(ETW)이 부여되고, 선박별·베이 단위 큐로 묶여 처리 순서가 정의(갑판/선창·양하/적하 구분).
  • 우선순위는 'ETD 임박 선박' × '크레인이 곧 처리할 작업'의 조합에서 가장 높다.

1.2 안벽크레인 연동 타이밍 (핵심 제약)

  • 양하: 크레인이 선박에서 내려 차량에 적재 → 야드 운반 → 블록 하차.
  • 적하: 차량이 야드 블록에서 픽업 → 크레인으로 운반 → 크레인이 선박에 적재.

차량이 적시에 공급되지 않으면 크레인이 대기한다. 안벽 생산성은 선박 체류 시간과 직결되므로 차량 미공급에 의한 크레인 대기는 최대의 손실 요인이며, 1차 목표는 이 대기 최소화이다.

작업-ETA 산정 요소설명
단위 작업 처리시간크레인 및 작업 유형(양하/적하)에 따라 상이
트윈 처리1회에 2개 동시 처리 → 처리 횟수 < 컨테이너 수
베이 변경다른 베이로 횡행(갠트리) 이동 시 추가 시간
해치커버 작업갑판↔선창 전환 시 덮개 개폐로 추가 시간

선행시간(리드타임): 작업 시점보다 앞서 출발시켜야 하는 시간. 적하는 야드 블록 경유 왕복을 포함해 양하보다 현저히 길다 → 작업 유형별 구분 적용.

2. AMR 작업 할당 요구사항

번호요구사항근거
R1마감 인지: 각 작업의 '크레인이 차량을 필요로 하는 시각'을 선박 ETD에서 크레인 잔여 작업 역산으로 산정.1.1·1.2
R2이동시간 보정: 적시 도착하도록 구간 이동시간(선행시간)만큼 앞서 출발 지시.1.2
R3작업 유형 구분: 적하는 블록 경유 왕복으로 선행시간이 길어 구분 적용.1.2
R4과·과소 배차 회피: 과조기=차량 대기 손실, 과지연=크레인 대기 손실 → 균형.1.2
R5위치 기반 매칭: 차량별 이동시간이 달라, 전체 도착시간 최소화하도록 배정.1.2
R6불확실성 대응: 예측 오차에 민감하지 않은 구조 채택.전반

3. 작업 우선순위 기준

  1. 마감 긴급도: 출항·크레인 처리까지 여유가 적을수록 우선.
  2. 크레인 대기 위험: 잔여 작업이 곧 소진되는 크레인에 공급되는 작업 우선.
  3. 이동 실현성: 마감 내 도착 가능성 평가, 불가하면 더 근접 차량 배정.
  4. 총비용 최소화: 개별이 아닌 시스템 전체 도착시간·유휴 최소화.
원칙

크레인 대기 방지(기준 2)를 차량 가동 효율(기준 4)에 우선한다. 동일 조건에서는 총비용이 낮은 배차를 선택한다.

4. 제안 로직 — 2단계 배차

4.1 1단계 — 수요 결정 (위치 비고려) → R1·R3·R4 / 우선순위 1·2

  • 크레인별 잔여 작업을 타이밍 모델로 산정해 각 컨테이너의 작업-ETA 도출.
  • 선박 ETD로부터 역산: 배차 마감 = 작업-ETA − 선행시간.
  • 산출물 = 현 시점에 차량 배차가 필요한 작업 목록. 위치 미고려라 위치 예측 오차가 마감 판정에 영향 없음(R6).

4.2 2단계 — 최적 매칭 (위치 고려) → R2·R5 / 우선순위 3·4

  • 1단계 후보 작업 × 후보 차량(유휴·임박 유휴)을 이동시간 비용행렬로 매칭(할당 문제). 비용 = 가용시점(유휴까지 남은 시간) + 공차 이동시간, 이동시간 = 순수 주행시간(주행 구간 시간)(경로 정체 포함·도착 후 핸드오버 대기 제외).
  • 도착지 대기(크레인 앞 큐)는 이동시간에서 제외. 줄서기는 도착 이후(크레인 스케줄) 생기는 것. (한때 "크레인별 진입 대기"로 1단계에 넣으려 했으나 그 대기가 거의 0이라 2026-07-01 폐기.)
  • 위치 예측은 후보 간 상대 비교에만 쓰여 절대 오차 영향이 작다(R6).
요약

1단계가 우선순위(마감·크레인 대기 위험)를 결정하고, 2단계가 이를 충족하는 최소비용 매칭을 산출한다.

5. 기대효과

  • 안벽 생산성 향상 — 크레인 대기 감소로 처리량↑·체류 시간↓.
  • 출항 마감 준수율 향상 — ETD 역산·우선순위화로 마감 내 완료 가능성↑.
  • 차량 운영 효율 향상 — 과조기 배차 감소로 더 적은 가동으로 처리.
  • 자동화 시스템 연계 — 데이터 기반 규칙을 AMR 운영 의사결정 로직으로 직접 활용.
  • 운영 일관성 — 명시적 기준으로 운영자 개인 경험 의존도↓.
