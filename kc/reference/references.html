참고자료

외부 명세·도구 링크와 내부 코드 위치, 운영 환경.

레퍼런스

내부 (코드·운영)

  • 라이브 GPS 적재 + 사이클 상태머신 · 배차 매처: crates/api/src/livemap.rs
  • 사이클 이력 API: crates/api/src/cycles.rs(/api/tt-cycles/*)
  • 도로망 라우터(방향 Dijkstra) + 비용 곡선: crates/api/src/roadgraph.rs(RouteCost/CostCurve)
  • 도로망 재추론 cron: scripts/reinfer_roadgraph.sh(GPS→스켈레톤→링크·매시)
  • 학습·정확도 하니스: crates/api/src/learn.rs
  • DB 마이그레이션: db/migrations/(최신 0080대 — 도로망 비용 전환·격자 룩업 폐기 등)
  • 대시보드 프론트엔드: web/src/(CYCLES 페이지 = CyclesPage.tsx)
  • 지식센터(이 사이트): kc/ — 손수 만든 정적 HTML(빌드 단계 없음), 공용 셸은 kc/assets/kc.js가 클라이언트에서 주입. 운영 API가 kc/를 /kc/ 경로로 서빙.

운영 환경

  • DB: PostgreSQL 17 · postgresql://wp:wp@127.0.0.1:5433/wp_tt
  • API 서비스: systemctl --user {restart,status} tt-api.service(release 빌드 실행)
  • 대시보드: http://100.95.189.16:8080(Tailscale) · 지식센터 /kc/
  • 시간대: DB·로그는 UTC, 사람이 보는 시각은 터미널 현지 MYT(UTC+8)로 변환(터미널=말레이시아 Westports/Port Klang)

외부 (도구·표준)

  • Open-Meteo — 날씨(기온·강수) 무료 API. 이동시간 모델의 우천 피처 원천.
  • 헝가리안(Kuhn–Munkres) 알고리즘 — 2단계 최소비용 매칭.
  • 다익스트라 최단경로 — 도로망 방향 라우팅.
