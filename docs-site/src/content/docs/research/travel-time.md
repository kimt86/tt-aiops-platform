**상태:** `진행중`(야간 P1~P5 배포·누적 시작) · **최종 검토:** 2026-06-16

배차 의사결정의 입력은 셋입니다 — **① 차량의 작업 완료 시점**, **② 완료 지점**, **③ 완료지점에서 후보 작업지점까지 이동시간**. ①②는 이미 있고(아래), 본 노트는 **③ OD 이동시간 모델**을 희소·부정확한 v0에서 존 기반 v1으로 재설계한 기록입니다.

> **출처 등급:** **[코드]** · **[DB]** = 서빙 Postgres · **[외부]** = Open-Meteo · (미검증).

## 한 장 요약

1. **① 완료 시점:** `free_in_s`(곧 빔 ~N분) — 도착 8분·운반 17분·임박 2분, `tt_cycle_v2`로 측정·검증([[/kc/research/soon-idle-tos/|곧유휴 연구]]). 표시 전용(그림자).
2. **② 완료 지점:** 작업점 코드(`topos1`/사이클 `legs.target`) + 학습 중심좌표 → lat/lon. 라이브.
3. **③ OD 이동시간 — 재설계:** 키를 **작업점 풀코드 → 존**으로. **블록 = 블록+베이**(단 제거), **안벽 = ~150m GPS 격자**(QC ID는 레일 위를 이동해 고정 위치가 아님 → 핸드오버 물리좌표로 앵커). + 피처 **날씨·시간대(dow)·혼잡도·차량**.

## 왜 존인가 — v0의 두 문제 [DB]

v0는 OD 키가 작업점 풀코드(`06T-3233`, `C21`)였습니다.

| 문제 | 측정 | 처방 |
|---|---|---|
| **블록 희소** | 고유 OD쌍 23,630 중 신뢰(n≥10) **136뿐** (~1.4표본/쌍) | 베이 단위 버킷 |
| **안벽 앵커 오류** | QC 43개로 빽빽해 *보이지만*, QC가 이동해 같은 `C21`이 시점마다 다른 물리위치 | GPS 격자 |

## 재설계 — 존 키 (`travel_zone`) [코드]

- **블록:** `블록 + 베이`(접미 앞 2자리). `01F-0708 → 01F-07`. 단(tier)은 주행시간과 무관해 제거.
- **안벽/이동크레인:** 캡처한 **핸드오버 GPS를 ~150m 격자**로. `Q<round(lat/0.00135)>_<round(lon/0.00135)>`. QC ID 대신 물리위치 → 두 QC가 같은 곳이면 같은 존, 한 QC가 두 곳이면 두 존.
- **하이브리드:** 그룹(중앙값 학습)은 존, **거리(dist_m)는 미세 topos 좌표**로 계산 → 밀도와 미세위치 둘 다.

:::caution[블록+베이는 밀도를 거의 안 늘린다 — 측정으로 확인]
블록만=297, **블록+베이=3,931 ≈ 풀코드 3,938**. 카디널리티가 베이/열에 몰려 있어 단 제거 효과 거의 없음. 따라서 블록측 밀도 향상은 미미하고, **밀도는 안벽 GPS격자(전방 누적)와 거리÷속도 폴백**이 견인. 사용자 결정(베이 해상도 유지 + 폴백 의존)을 반영.
:::

## 피처 (정확도용) [코드/외부]

| 피처 | 소스 | 상태 |
|---|---|---|
| 거리(dist_m) | 학습 topos 좌표 haversine | 가동 |
| 시간대(dow·hour) | 사이클 시각 | 가동(소급 백필) |
| 혼잡도(congestion) | 도착시점 동시 in-flight 사이클 수 | 전방 가동 |
| **날씨**(강수·풍속·시정) | **Open-Meteo** 시간별 → `weather_hourly`, 시각 조인 | 가동(누적) |
| 차량/운전자 | `ytno` | 보유 |

## 야간 검증/발견

- **존 confident=0 vs 풀코드 confident=146 (일시적 하락).** 기존 146은 대부분 *이동하는 QC-ID*로 뭉친 **가짜 밀도** — 우리가 의도적으로 해체. 물리 안벽격자는 막 누적 시작 → **밤새 채워지며 회복 예상.** `learn_travel_metric.confident_zone_pairs`로 곡선 추적.
- **날씨 무신호(우천=건조 509s).** 날씨 표본 2일·우천시간 적음 → 누적 후 재평가.
- 안벽 좌표 적재율은 Phase 2 재시작 이후 사이클부터 누적(완료 ~20분 소요) → 시간당 상승.
