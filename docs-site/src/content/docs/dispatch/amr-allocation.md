본 문서는 자동화 운반차량(AMR, Autonomous Mobile Robot) 기반 차량 운영 시스템 도입을 위한
작업 할당·스케줄링 로직을 제안하는 자료이다. 컨테이너 터미널 작업은 ① 작업 우선순위,
② 안벽크레인 연동 타이밍 측면에서 고유한 운영 특성을 가지며, 본 문서는 이 특성으로부터 AMR
작업 할당의 **요구사항**과 **우선순위 기준**을 도출하고, 이를 충족하는 **2단계 배차 로직**을
제안한다.

여기서 **‘작업 할당’은 어느 작업을 어느 차량이 수행할지**를, **‘작업 우선순위’는 후보 작업들
가운데 어느 것을 먼저 처리해야 하는지**를 의미한다.

본 문서는 개념 수준의 요구사항을 다루며, 구체적 수치(처리시간·선행시간 등)는 별도 상세 설계
자료에서 제시한다. 주요 용어는 본문 첫 등장 시 정의하고 말미 [용어 정리](#용어-정리)에 종합한다.

## 1. 작업 할당이 반영해야 할 터미널 운영 특성

### 1.1 작업 우선순위 체계

작업 우선순위란 처리 대기 중인 후보 작업들 가운데 어느 것을 먼저 차량에 할당해야 하는지의
순서를 의미한다.

- 작업 우선순위의 최상위 기준은 **선박 출항 예정시각(ETD)** 이다. 각 선박은 ETD 이전에
  **양하**(선박에서 내리는 컨테이너)와 **적하**(선박에 싣는 컨테이너) 물량을 모두 완료해야 한다.
- 작업의 최소 단위는 컨테이너 1개의 **단위 작업(move)** 이며, 각 작업은
  **상태(계획 → 대기 → 진행 → 완료)** 로 관리된다. ‘대기’는 운반차량이 아직 배정되지 않은
  미충족 수요, ‘진행’은 차량이 배정되어 처리 중인 작업이다.
- 각 단위 작업에는 **예정 작업시각(ETW)**, 즉 안벽크레인이 해당 컨테이너를 처리할 예상 시점이
  부여된다. 작업은 선박별·**베이(선박 내 구획)** 단위 큐로 묶여 처리 순서가 정의되며,
  갑판/선창 및 양하/적하로 구분된다.
- 결과적으로 우선순위는 **‘ETD가 임박한 선박’ × ‘안벽크레인이 곧 처리할 작업’** 의 조합에서
  가장 높게 형성된다. 출항까지 여유가 큰 작업은 동일 작업이라도 시급성이 낮다.

### 1.2 안벽크레인 연동 타이밍 (핵심 제약)

안벽크레인(QC)은 컨테이너를 순차적으로 처리하며, 운반차량은 크레인이 연속 작업을 유지하도록
적시에 공급되어야 한다.

- **양하**: 크레인이 선박에서 컨테이너를 내려 차량에 적재 → 차량이 야드로 운반 → 야드 블록에 하차.
- **적하**: 차량이 야드 블록에서 컨테이너를 픽업 → 크레인 위치로 운반 → 크레인이 선박에 적재.

운반차량이 적시에 공급되지 않으면 안벽크레인은 다음 컨테이너를 처리하지 못하고 **대기**한다.
안벽 생산성은 선박 재항(체류) 시간과 직결되므로 **차량 미공급에 의한 크레인 대기는 최대의 손실
요인**이며, AMR 작업 할당의 1차 목표는 이 대기 시간의 최소화이다.

안벽크레인이 특정 컨테이너를 처리하는 시각은 다음 요소들의 영향을 받으며, 이를 종합하여
산정한다:

| 요소 | 설명 |
|---|---|
| 단위 작업 처리시간 | 크레인 및 작업 유형(양하/적하)에 따라 상이 |
| 트윈 처리 | 일부 작업은 1회에 컨테이너 2개를 동시 처리하여 처리 횟수가 컨테이너 수보다 적음 |
| 베이 변경 | 크레인이 다른 베이로 횡행(갠트리) 이동 시 추가 시간 소요 |
| 해치커버 작업 | 갑판↔선창 전환 시 덮개 개폐로 추가 시간 소요 |

- **선행시간(리드타임)**: 차량을 작업 시점보다 앞서 출발시켜야 하는 시간. 양하는 공차 차량이
  크레인 위치로 이동하는 시간인 반면, 적하는 야드 블록을 경유하여 컨테이너를 픽업하는 왕복을
  포함하므로 선행시간이 **현저히 길다**. 따라서 작업 유형별로 구분하여 적용해야 한다.

위 요소를 종합한 타이밍 모델로 ‘안벽크레인이 각 컨테이너를 처리하는 시각’을 산정하고, 차량은
해당 시각보다 선행시간만큼 앞서 도착하도록 배차되어야 한다.

## 2. AMR 작업 할당 요구사항

1장의 분석으로부터 다음 요구사항을 도출한다.

| 번호 | 요구사항 | 근거 |
|---|---|---|
| **R1** | **마감 인지**: 각 작업의 ‘안벽크레인이 차량을 필요로 하는 시각’을 산정한다(선박 ETD에서 크레인 잔여 작업을 역산). | 1.1, 1.2 |
| **R2** | **이동시간 보정**: 차량이 적시에 도착하도록 구간 이동시간(선행시간)만큼 앞서 출발을 지시한다. | 1.2 |
| **R3** | **작업 유형 구분**: 적하는 야드 블록 경유 왕복으로 선행시간이 양하보다 현저히 길므로 구분 적용한다. | 1.2 |
| **R4** | **과·과소 배차 회피**: 과조기 배차는 차량 대기 손실, 과지연 배차는 크레인 대기 손실을 초래하므로 균형이 필요하다. | 1.2 |
| **R5** | **위치 기반 매칭**: 차량마다 작업 위치까지의 이동시간이 다르므로, 어느 차량을 어느 작업에 배정할지 결정하여 시스템 전체 도착시간을 최소화한다. | 1.2 |
| **R6** | **불확실성 대응**: 데이터와 예측에 불확실성이 존재하므로, 예측 오차에 민감하지 않은 구조를 채택한다. | 전반 |

## 3. 작업 우선순위 기준

후보 작업들 가운데 어느 것을 먼저 차량에 할당할지를 결정하는 우선순위 기준은 다음과 같다.

1. **마감 긴급도**: 선박 출항 및 크레인 처리 시점까지 남은 여유가 적을수록 우선순위가 높다.
2. **크레인 대기 위험**: 잔여 작업이 곧 소진되는 안벽크레인에 공급되는 작업을 우선한다.
3. **이동 실현성**: 마감 내 도착이 가능한지 평가하며, 불가능한 경우 해당 작업에는 더 근접한
   차량을 배정한다.
4. **총비용 최소화**: 개별 차량이 아닌 시스템 전체의 도착시간 및 유휴를 최소화한다.

> 원칙: **크레인 대기 방지(기준 2)를 차량 가동 효율(기준 4)에 우선한다.** 동일 조건에서는 총비용이
> 낮은 배차를 선택한다.

## 4. 제안 로직 — 2단계 배차

데이터와 예측에 불확실성이 존재하므로, **‘무엇을 처리할 것인가(수요)’** 와
**‘어느 차량을 배정할 것인가(공급)’** 를 분리하여 설계한다.

### 4.1 1단계 — 수요 결정 (위치 비고려) → R1·R3·R4 / 우선순위 1·2

- 크레인별 잔여 작업을 1.2의 타이밍 모델로 산정하여 각 컨테이너의 **작업 예정시각(작업-ETA)** 을
  도출한다.
- 선박 **ETD로부터 역산**하여 **배차 마감 = 작업-ETA − 선행시간** 을 산출한다. 이는 해당 작업에
  차량을 배차해야 하는 최종 시점이다.
- 산출물은 **현 시점에 차량 배차가 필요한 작업 목록** 이다. 본 단계는 차량 위치를 고려하지
  않으므로, 위치 예측 오차가 마감 판정에 영향을 주지 않는다(R6).

### 4.2 2단계 — 최적 매칭 (위치 고려) → R2·R5 / 우선순위 3·4

- 1단계의 후보 작업과 후보 차량(유휴 및 임박 유휴 차량)을 **구간 이동시간 비용행렬**로 매칭하여
  (할당 문제) 최적 배차를 도출한다.
- 위치 예측은 후보 간 **상대 비교**에만 사용되므로 절대 오차의 영향이 작다(R6).

> 요약: 1단계가 우선순위(마감·크레인 대기 위험)를 결정하고, 2단계가 이를 충족하는 최소비용
> 매칭을 산출한다.

## 5. 기대효과

- **안벽 생산성 향상**: 차량 미공급에 의한 안벽크레인 대기를 줄여 시간당 처리량을 높이고, 선박
  재항(체류) 시간을 단축한다.
- **출항 마감 준수율 향상**: 작업을 출항 예정시각 기준으로 역산·우선순위화하여, 마감 내 작업
  완료 가능성을 높인다.
- **차량 운영 효율 향상**: 과조기 배차로 인한 차량 대기를 줄여, 동일 작업량을 더 적은 차량
  가동으로 처리할 수 있다.
- **자동화 운영 시스템 연계**: 데이터 기반의 작업 할당·우선순위 규칙을 제공하여, 자동화 운반차량
  운영 시스템의 의사결정 로직으로 직접 활용할 수 있다.
- **운영 일관성 확보**: 우선순위와 할당 기준을 명시적으로 적용하여, 운영자 개인 경험에 대한
  의존도를 낮추고 일관된 운영을 가능하게 한다.

## 용어 정리

| 용어 | 정의 |
|---|---|
| AMR | 자동화 운반차량(Autonomous Mobile Robot). 컨테이너를 운반하는 자율주행 차량. |
| 안벽크레인(QC) | 선박과 부두 사이에서 컨테이너를 양·적하하는 크레인. |
| 양하 / 적하 | 양하: 선박 → 야드. 적하: 야드 → 선박. |
| ETD | 선박 출항 예정시각. |
| ETW | 컨테이너별 예정 작업시각(안벽크레인 처리 예상 시점). |
| 단위 작업(move) | 컨테이너 1개의 이동을 1회로 세는 작업 단위. |
| 트윈 처리 | 1회에 컨테이너 2개를 동시 처리. |
| 베이 | 선박 내 길이 방향 구획. 베이 변경 시 크레인 횡행 이동이 발생. |
| 선행시간(리드타임) | 작업 시점보다 앞서 차량을 출발시켜야 하는 시간. |
| 작업-ETA | 안벽크레인이 특정 컨테이너를 처리할 것으로 산정된 시각. |
| 배차 마감 | 작업-ETA에서 선행시간을 차감한, 차량 배차의 최종 시점. |
